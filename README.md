# init_tasks

Monorepo for `init_tasks`, a pure-Dart scheduler for app initialization:
declare dependencies between init tasks, run them in topological order
with parallel levels.

## Packages

| Package | Description |
|---|---|
| [`init_tasks`](init_tasks) | Runtime: `InitTask`, `InitScheduler`, `@Init` annotation |
| [`init_tasks_builder`](init_tasks_builder) | build_runner generator: `@Init` → `buildInitScheduler()` |
| [`example`](example) | Annotated app-init example (pure Dart) |

## Usage

```dart
@Init()
class InitConfig extends InitTask {
  @override
  Future<void> run() async { /* ... */ }
}

@Init(dependsOn: [InitConfig])
class InitDatabase extends InitTask {
  @override
  Future<void> run() async { /* ... */ }
}

// generated by init_tasks_builder:
Future<void> main() => buildInitScheduler().run();
```

## Agent skill

Other agents can use this library through the bundled skill at
[`skills/init-tasks`](skills/init-tasks) (`SKILL.md`): it covers the
annotation workflow, the manual API, scheduling semantics, and the typed
error list.

**Skill Add** — install with the [skills CLI](https://github.com/vercel-labs/agent-skills):

```sh
npx skills add lwj1994/dag_task_scheduler --skill init-tasks
```

Useful flags: `-g` installs globally (`~/.<agent>/skills/`) instead of
per-project; `-a <agent>` targets one agent (e.g. `claude-code`,
`cursor`); `-y` skips prompts; `--list` previews without installing.

## Development

This repo uses [melos](https://melos.invertase.dev/).

```sh
dart pub global activate melos
melos run analyze   # dart analyze .
melos run format    # dart format .
```

```sh
cd example && dart run build_runner build
```
